The Maker Sumo RP2350 is a sumo robot controller from Cytron Technologies. Everything a mini sumo robot needs is on the board: a dual-channel DC motor driver, inputs for five opponent sensors and two edge sensors, an IR start module input, two servo outputs, and a buzzer, button, DIP switches and potentiometer.

## Technical details

- Raspberry Pi RP2350A: dual-core Arm Cortex-M33 at 150 MHz, 520 KB RAM
- 2 MB flash
- Dual-channel DC motor driver with PWM + DIR control and fault outputs
- Over-current (OC) and fault indicator LEDs for the motor driver
- 5 digital opponent sensor inputs (left, front-left, front-centre, front-right, right)
- 2 analog edge sensor inputs
- IR start module input
- 2 servo outputs
- Potentiometer, 3-way DIP switch, user button, user LED and piezo buzzer
- Motor supply voltage monitoring
- USB-C for programming and power
